Anexo · El repo

Cómo está armado
el repo.

El repo Campa-aMKT-26-27 es la carpeta de trabajo de marketing en GitHub. Tiene dos partes: los documentos para pensar y producir, y la carpeta docs/, que se publica sola como sitio web. Es público: cualquiera puede leerlo, así que nada comercial interno se sube acá.

04 · Lo que falta (lo hace Alvaro)

Un clic en GitHub.

  1. Poner main como rama por defecto: en GitHub, Settings → General → Default branch → elegir main. Así cada sesión nueva de Claude arranca desde ahí.
  2. Borrar las ramas viejas (opcional, cuando quieras): ya están integradas.
