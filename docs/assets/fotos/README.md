# Fotos reales para la página de Nidera

Subí acá las **fotos reales de la zona** y las monto en la galería de
`docs/nidera/` (sección "La zona en imágenes").

## Qué subir (por orden de valor)
1. **Lotes de la zona** — maíz y girasol en Henderson, Daireaux, Bolívar.
2. **Días de campo / ensayos / siembra** — la actividad real.
3. **El equipo HenderSeeds** — caras, oficina, recorridas.
4. **Cosecha / resultados** — con permiso del productor si aparece gente.

## Cómo prepararlas
- **Web-optimizadas:** 1600 px de ancho máximo, formato **JPG**, < 500 KB c/u.
  (Las fotos crudas del celular pesan demasiado para la web.)
- **Nombre descriptivo:** `foto-lote-girasol-henderson.jpg`, `foto-equipo-oficina.jpg`, etc.

## Lo que NO va acá
- **Videos pesados** → GitHub rebota archivos de +100 MB. Subí el video a
  YouTube / Drive / Vimeo y pasame el link: lo embebo en la página.
