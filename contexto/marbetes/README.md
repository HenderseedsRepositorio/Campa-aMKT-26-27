# Marbetes de híbridos — PDFs oficiales Nidera

Acá van los **marbetes oficiales (PDF)** de cada híbrido de maíz y girasol
de la campaña 26/27. Son la fuente de verdad para fichas técnicas, traits,
densidades y datos de ensayo.

## Cómo nombrar los archivos
Usar el formato: `marbete-[CULTIVO]-[NOMBRE-HIBRIDO].pdf`

Ejemplos:
- `marbete-maiz-NS7626-VIPTERA3.pdf`
- `marbete-girasol-NS1113-CL.pdf`

## Cómo subirlos desde el celular o la compu
1. Entrá al repo en GitHub → carpeta `contexto/marbetes/`.
2. **Add file → Upload files**.
3. Arrastrá o elegí los PDFs.
4. **Commit** (botón verde).

## Qué hago yo con los marbetes
Los leo y extraigo la data técnica de cada híbrido para completar
`contexto/productos-26-27.md`: tecnología/trait, posicionamiento,
densidades, datos de ensayo citables y argumentos de venta.
Con esa info cargada, los posts de producto salen con datos reales
en vez de `[COMPLETAR]`.
