# Referencias visuales — posteos reales de Henderseeds

Acá van **capturas de posteos que Henderseeds ya publicó**, para que Claude calque
el estilo real (colores, tipografías, formato, uso del logo, tono de los textos).

> Claude no puede ver el Instagram (@henderseeds) directamente desde la sesión web
> (Instagram pide login y el entorno bloquea esas páginas). Pero **sí puede leer
> las imágenes que subas a esta carpeta.**

## Qué subir (ideal: 3 a 5 capturas)
- El **posteo de lanzamiento** de la precampaña 26/27 (para mantener coherencia).
- 1–2 **placas típicas** de producto (maíz o girasol).
- 1 **carrusel** o historia, si tenés.
- Cualquier pieza cuyo estilo te guste y quieras repetir.

## Cómo subirlas desde el celular
1. Entrá al repo en GitHub → carpeta `brand/referencias/`.
2. **Add file → Upload files**.
3. Arrastrá o elegí las capturas. Nombralas `ref-01-tema.jpg`, `ref-02-tema.jpg`, etc.
4. **Commit** (botón verde).

## Qué hago yo con eso
Leo las imágenes y extraigo: paleta exacta (hex), tipografías, grilla/formato,
cómo y dónde va el logo, y el tono de los captions. Lo documento en
`brand/identidad.md` y `brand/tono-voz.md` para que **todos los posteos futuros
salgan en tu línea**, no genéricos.
